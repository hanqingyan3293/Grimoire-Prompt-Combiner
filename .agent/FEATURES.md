## 1. 工作区（顶栏预设）

顶栏「创作 / AI / 识图 / 图片参考 / 标签管理 / 标签与资产」六个预设，点击即切换整组面板布局。标签/图库相关的是：

| 工作区 | 面板组合 | 用途 |
|---|---|---|
| **创作** | 标签侧栏 + 提示词工作区 + 工具侧栏 | 选标签、组提示词 |
| **标签管理** | 标签侧栏 + 提示词工作区 + 提示词资产 | 标签库维护、资产浏览 |
| **标签与资产** | 标签侧栏 + 标签与资产 + 提示词资产 | 关系编辑、候选确认、反查 |
| **图片参考** | 标签侧栏 + 图片 + 历史 | 图片库浏览 |

## 2. 标签侧栏（左栏）

打开方式：默认在「创作 / 标签管理 / 标签与资产 / 图片参考」工作区的左栏；或通过面板菜单添加「标签侧栏」。

### 2.1 分类树浏览
- **展开大类** → 显示子类列表（每个子类标注标签数量）
- **点击子类** → 中栏渲染该子类的标签卡片（可多选子类，多选时依次排列）

### 2.2 标签卡片操作
| 操作 | 效果 |
|---|---|
| 单击 | 加入正面提示词（再次单击取消） |
| 右键 | 打开菜单：加入负面 / 收藏 / 编辑标签 / 删除标签 |
| 三态显示 | 已选（实线高亮）/ 被隐含（虚线，点击转为显式选中）/ 未选 |

### 2.3 分组浏览（TagMaster 语义）
- **入口**：标签卡片区顶部的「分组浏览（按命名空间）」勾选框
- **用法**：勾选后，下方出现命名空间下拉（值来自 `tag_metadata.namespace`），选中某个命名空间即只显示该组的标签；「未分组」选项显示没有命名空间的标签
- **数据来源**：标签元数据编辑器设置（见 4.3）

### 2.4 搜索
- **入口**：侧栏顶部「搜索…」输入框
- 支持中文、英文、别名与标签关系命中

## 3. 提示词工作区（中栏）

打开方式：默认在「创作 / 标签管理」工作区的中间区域（面板类型「提示词工作区」）。

### 3.1 工具栏按钮
| 按钮 | 功能 |
|---|---|
| 去重 | 合并重复标签（权重按 BDTM 语义求和） |
| 随机抽取 | 从可用标签中随机取 N 个（N 范围在设置中配置） |
| 清正面 / 清负面 | 清空对应分区 |
| 全部清空 | 清空全部 |

### 3.2 权重编辑（BDTM 语义）
每个标签芯片上：
- **滑杆**：0.1–2.0 连续调节
- **数字输入**：精确值
- **±1 层括号按钮**：`−` 降低一层（÷1.1）、`+` 提高一层（×1.1），效果直接体现在输出
- **× 移除**：从提示词移除

### 3.3 输出区
- 实时显示合成后的提示词（正负面合并、BREAK 换行、括号权重）
- **复制中文 / 复制英文** 按钮
- **放大镜按钮**：打开输出预览浮层（同样含复制按钮）

### 3.4 标签补全（TagAutocomplete）
出现位置：任何需要输入标签的地方（批量标注、图库筛选、标签反查等）。
- 输入 2 个字符后自动弹出（250ms 防抖）
- ↑/↓ 键导航，Enter 选择（**输入法组字期间的 Enter 不会误选**）
- 结果显示别名徽标与使用次数排序
- Esc 关闭

## 4. 标签与资产面板

打开方式：面板菜单添加「标签与资产」；或切到「标签与资产」工作区。三个页签：

### 4.1 标签字典（搜索页签）
| 操作 | 效果 |
|---|---|
| 搜索 | 按中文/英文/别名搜索标签 |
| 点击结果 | 打开详情：别名管理、**元数据编辑**、关系管理 |
| 关系按钮 | 把当前标签与另一标签建立关系（相关/推导/冲突/父级） |
| **同名消歧义** | 搜索结果中出现同名标签时，自动显示分类归属（如 `[人物/性别]`）并高亮该行 |

### 4.2 候选标签（确认页签）
- **筛选**：按来源（WD14/提示词解析/AI 识图/导入）与最低置信度
- **接受选中 / 拒绝选中**：批量处理
- **创建标签**：为候选项创建新标签并映射
- **映射**：把候选指向已有 tagId

### 4.3 元数据编辑器（TagStudio 语义）
位置：标签详情区的「元数据」小节。
| 字段 | 说明 |
|---|---|
| 命名空间 | 用于分组浏览（见 2.3）与标签搜索过滤 |
| 颜色 | `#RRGGBB` 格式 |
| 描述 | 标签说明文字 |
| 启用该标签 | 开关；**关闭后该标签从搜索与补全中隐藏**（管理视图仍可见并标注「已禁用」） |
| **保存元数据** | 写入（主进程校验格式，无效时如实报错） |

**「已禁用」的行为**：禁用标签不会出现在普通搜索、标签补全与分组浏览里；标签字典（本面板）显式包含它们并显示灰色「已禁用」徽标，便于重新启用。这是「启用该标签」开关的真实语义（此前该开关只写入、无消费者）。

### 4.4 资产标注（页签）
- **按资产查标签**：选资产类型（图片/提示词资产/画布节点）+ 输入资产键（如 `image:12`）→「读取资产标签」
- **按标签反查资产**（Hydrus 语义，唯一的 tag→asset 查询入口）：
  1. 用标签补全加入一个或多个筛选标签
  2. 选匹配逻辑：任一标签 / 全部标签 / 排除标签
  3. 可勾选「包含隐含子标签」（沿推导关系展开）
  4. 点「反查」→ 列出匹配的资产键与命中标签数

## 5. 标签批量工具（标签与资产面板内）

打开方式：面板菜单添加「标签与资产」→ 顶部第 4 个页签「批量工具」。（2026-11-26 前它是独立面板，旧布局会自动落到本页签。）

### 流程：筛选 → 操作 → dry-run → 应用

| 步骤 | 控件 |
|---|---|
| **目标筛选** | 资产类型（图片/提示词资产/画布节点）、标签筛选（补全选择）、匹配逻辑（任一/全部/排除）、「仅空文件（无任何标签的资产）」 |
| **操作** | 添加标签 / 删除标签 / 替换标签（替换时填源标签与目标标签） |
| **dry-run 预览** | 显示匹配资产数、预计写入条数、样例资产键 |
| **应用** | 超过 200 个资产时弹出二次确认；分块执行（500/批） |

**安全设计**：没有 dry-run 不能应用；空目标集合拒绝应用。

## 6. 图库搜索面板

打开方式：面板菜单添加「图库搜索」。左中右三栏 + 底部操作条。

### 6.1 筛选轨（左栏）
| 区块 | 控件 |
|---|---|
| 来源 | 导入参考 / ComfyUI 生成 / API 生成 / 项目包 / 画布上传（多选） |
| 收藏 | 任意 / 已收藏 / 未收藏 |
| 最低评分 | 不限 / 1–5 星 |
| 标签筛选 | 标签补全添加；匹配逻辑（任一/全部/排除）；「包含隐含子标签」 |
| 重置筛选 | 清空全部条件 |

### 6.2 工具栏（顶部）
| 控件 | 功能 |
|---|---|
| 搜索图库 | 文件名/内容搜索（250ms 防抖） |
| 排序方式 + 方向 | 最近更新 / 创建时间 / 评分 / 名称，升序/降序 |
| 选择区 | 「选择全部筛选」（SDIS 语义的筛选结果全选）/「清除选择」；显示已选数或「全部筛选结果（N 个资产）」——**N 来自后端真实计数** |
| 保存当前搜索 | 输入名称 → 保存（含筛选与排序） |
| **建立相似索引** | 计算全部图片的感知哈希（已配置 CLIP 时同时算嵌入）；显示进度；完成后提示索引数与 CLIP 状态 |
| **查找重复** | 按感知哈希距离分组显示重复组（组大小、代表哈希、成员图片 id）；每组可**直接处置**：见下 |
| **CLIP** | 配置面板：Python/模型诊断（可用性徽标、路径、模型数）、「选择模型目录」「选择 Python」按钮 |

**重复组处置**（检测 → 处理的闭环）：
- 每组右侧有「**保留首张，删除其余**」按钮（保留 id 最小的一张）
- 点击后弹出确认对话框，**列出将删除与保留的图片 id**，确认前不写任何数据
- 确认后逐张删除：托管副本与派生图从磁盘清理，**外链原文件绝不受影响**
- 删除完成后自动刷新重复列表与图库

### 6.2a 相似索引与 CLIP 的关系
- 不配置 CLIP 时：索引只算感知哈希（dhash+颜色直方图，纯本地），相似图标注「感知哈希」
- 配置 CLIP 后（工具栏 → CLIP → 选择模型目录）：索引同时计算 CLIP 嵌入，相似图自动升级为「CLIP 语义」
- 装好模型前「相似图」按钮要求先建索引（哈希通道即时可用）

### 6.3 语法查询栏
- **入口**：工具栏下方的「语法查询」输入框
- **语法**：`tag:` / `parent:` / `namespace:` / 通配 `*` / `AND` `OR` `-`(NOT) / 括号 / `[key=value]` / 引号短语 / 区间 `rating:4..5` / `source:` / `favorite:` / `sort:` / `order:` / `limit:`
- 示例（即占位符文本）：`tag:1girl -tag:lowres parent:expression rating:4..5 "文件名" sort:rating limit:120`
- 应用后显示谓词 chips；解析失败如实报错（如文本 OR、未知键）

### 6.4 虚拟网格（中栏）
- 200px 基准列宽自适应，滚动窗口化渲染
- 卡片：缩略图、文件名、来源徽标、**收藏星标（点击切换）**、**评分（点击调整）**、选中圈、「文件缺失」标记
- 交互：单击选中、Shift 单击范围选择、双击打开检查器、键盘 Enter 打开 / Space 选中

### 6.5 检查器（右栏，双击卡片打开）
| 区块 | 内容 |
|---|---|
| 标题行 | 文件名、可用状态、收藏、评分、尺寸、元数据来源（A1111/NovelAI/ComfyUI） |
| 动作 | **复制提示词** / **定位文件**（打开系统文件管理器）/ **反推**（提交 WD14 任务）/ **相似图** |
| **相似图区** | 点击「相似图」后显示：标注实际通道（「感知哈希」或「CLIP 语义」）、缩略图网格、相似度百分比；点击缩略图跳转到该图 |
| **连续探索**（相似图区内） | 勾选后点击相似缩略图会**自动以新图为起点重查**，可一路漫游相似链；「← 返回」按钮按来路后退（显示步数）。未勾选时点击只跳转，需手动再点「相似图」 |
| 生成参数 | 从嵌入元数据解析的 prompt/负面/模型/种子/采样器/步数/CFG；「解析内嵌参数」按钮手动触发 |
| 标签 | 当前标签（可移除、可补全添加） |
| 关联 | 媒体关系列表 |

### 6.6 保存的搜索（左栏底部）
| 控件 | 功能 |
|---|---|
| 点击条目 | 应用该搜索（筛选 + 排序） |
| **Pin 图标** | 固定为**智能文件夹**：条目显示星标 + **后端真实计数徽标**，排序置顶 |
| 删除 | 删除该保存搜索 |
| 导出 / 导入 | JSON 信封格式（`{version:1, searches:[...]}`），导入容忍裸数组 |
| 刷新 | 重新加载列表 |

### 6.7 底部操作条
- 分页（共 N 个 / 第 x/y 页 / 上一页 / 下一页）
- 选中数显示
- 批量添加标签（补全输入）+「批量标注」（对显式选中项）
- 说明：选择模式为「全部筛选结果」时，批量写入引导至标签批量工具面板（避免跨页假批量）

## 7. 图片资源库面板

打开方式：面板菜单添加「图片」；或「图片参考」工作区中栏。

### 7.1 顶栏按钮
| 按钮 | 功能 |
|---|---|
| 导入副本 | 选文件 → 复制进托管库（内容哈希去重） |
| 链接原文件 | 选文件 → 登记外部路径（不复制） |
| **扫描文件夹** | 选目录 → 递归扫描出图片清单（不导入） |
| **扫描生成元数据** | 批量为存量图片解析 A1111/NAI/ComfyUI 嵌入元数据，显示进度 |

### 7.2 扫描结果区（扫描后出现）
- 列出每个文件（大小 / 已导入标记），已导入项自动置灰并排最后
- 勾选要导入的文件
- **「导入副本（N）」/「链接原文件」** 两个按钮按对应模式导入
- **「按目录名写入标签」**（TagStudio folders→tags）：勾选后，导入时把相对目录路径的每一段作为标签写入（同名标签复用，缺失则创建并批量标注）

### 7.3 搜索与卡片
- 搜索框（文件名）、来源下拉、标签徽章点击筛选（可清除）
- 卡片：缩略图、文件名、托管/外链徽标、可用状态、来源徽标、标签徽章、收藏心形、1–5 星评分
- 多选（复选框）→ 批量标注（补全选标签）/ 批量删除
- 点缩略图打开大图预览（滚轮缩放、拖拽平移）

### 7.4 分页（大库支持）
- 库容量超过 60 张时，底部出现分页页脚：**共 N 张 · 第 x/y 页 · 上一页 / 下一页**（60/页）
- 总数来自后端计数（不受页内筛选影响）
- **筛选边界说明**（页脚原文）：搜索与标签筛选只作用于当前页；跨页精确筛选请用「图库搜索」面板
- 删除图片会**同时清理磁盘产物**：托管副本与派生图被移除，外链原文件不受影响

## 8. WD14 反推面板

打开方式：面板菜单添加「WD14 反推」。

### 8.1 运行环境
- 诊断徽标：Python 可用性、onnxruntime 可用性与版本、模型配对情况
- 「选择模型目录」「选择 Python」按钮（写入设置，重启 worker）

### 8.2 单模型反推
- 模型下拉（自动选择可用模型 / 指定模型）
- 阈值滑杆（0.01–0.99）
- 「待反推图片」网格，每张卡片有「反推」按钮

### 8.3 多模型合并反推（BDTM AutoTagger 语义）
- **入口**：「多模型合并反推」折叠区（模型数 > 1 时出现）
- 勾选 ≥2 个模型
- 「合并方式」下拉：**并集**（取每标签最高置信度）/ **交集**（只保留所有模型共同命中，取最小值）
- 反推时对每个模型依次执行并合并结果

### 8.4 卡片与历史
- **待反推图片网格**：每张卡片有「反推」按钮（逐张提交任务）；悬浮预览（500ms 延迟，含原图）
- **反推历史**：
  - 状态筛选 chips（全部 / 成功 / 失败）与搜索框（文件名、标签或模型）
  - 每行复选框多选 → 「批量反推」（对缺少图片 ID 的条目如实跳过并报告数量）
  - 每行「打开原图」按钮（系统文件管理器定位反推快照）
  - 点击行打开详情浮层：标签分组展示、「应用到正面提示词」按钮

## 9. 面板的添加与管理

- **添加**：任意面板的标题栏菜单 → 「添加面板」→ 按分组选择（核心 / 素材 / AI / 创作工具 / 设置）
- 标签/图库相关可添加面板：标签侧栏、提示词工作区、标签与资产（含批量工具页签）、图库搜索、图片、任务队列、WD14 反推、提示词资产
- **弹出为独立窗口**：面板标题栏的弹出按钮（不修改工作区布局文档）
- **分区**：面板可拖动分区、分割、作为标签页
