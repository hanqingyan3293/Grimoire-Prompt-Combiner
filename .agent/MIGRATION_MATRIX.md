# Grimoire migration matrix

This is the source-of-truth ledger for source-level migration. The seed rows below reflect the current repository baseline; Phase 0 expands them into function-level rows before implementation waves proceed.

## Required columns

| Field | Meaning |
|---|---|
| Feature | Atomic capability, not a vague subsystem label |
| Source project/version | Exact local snapshot |
| Source files/symbols | Concrete files and components inspected |
| Source implementation | Behavior and state transitions |
| License | Actual LICENSE/header result |
| Migration method | One of the allowed methods |
| Grimoire destination | Vendor/integration/renderer/main path |
| Required adaptation | IPC, theme, persistence, security, or type bridge |
| Parity evidence | Tests, screenshots, smoke flow, or source comparison |
| Status | Controlled status only |
| Blocker/rewrite proof | Required for BLOCKED or REIMPLEMENTED |
