## 参考实现的数据模型（抄形状，不抄代码）

```
work(id, name, origin_snapshot, saved, created_at, last_used_at, last_version_id)
version(id, work_id, parent_id, number, branch_id, branch_number,
        snapshot, source 'user'|'agent', operation, created_at)
branch_name(branch_id, name)
version_image(id, version_id, image_id, seed, variant, sort)
asset(id, kind, name, payload, order, uses, examples, created_at)
asset_usage(asset_id, image_id, used_at, via)   -- 参考实现没有，我们补
tag_dict(tag, display_tag, translation, category, translation_source, updated_at)
```

三条不变量：`parent_id` 与 `branch_id` 必须同 `work`；原文 raw 是唯一权威（标签行可重算）；所有编辑入口必须带修订号 + 编辑锁。

## 分支出规则（参考实现的核心只有一行）

父版本已有子版本 → 新版本把自己当作分支起点（`branch_id = 自己的 id`，`branch_number + 1`）；否则沿用父分支。
