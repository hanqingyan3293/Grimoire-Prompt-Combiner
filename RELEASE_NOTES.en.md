## Highlights

- Infinite-canvas projects now use a single project document with revision protection, serialized saves, retryable failures and workspace-switch protection.
- Prompt libraries and prompt assets support collapsible source, category and subcategory trees, custom categories and drag-and-drop organization.
- Main-app and canvas previews share the same draggable, resizable, scrollable window structure.
- Image previews support 0.1x–10x zoom, pointer-centered zoom and left-button panning.
- Theme preferences synchronize between the host window, toolbar settings and the canvas iframe.
- Settings pages, provider cards, asset cards, dialogs and panel boundaries received spacing and layout refinements.
