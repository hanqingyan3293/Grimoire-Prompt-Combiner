# 魔导书 Grimoire v7.1 简单介绍

最近整理了一下自己的 AI 绘图提示词工具，项目名叫 **魔导书 Grimoire**。

它主要是一个 Windows 桌面端的提示词组合器，用来管理标签、组合正面和负面提示词，也可以配合 AI 助手、识图和图片参考功能一起使用。这个项目不是什么复杂的大软件，更多是为了让自己在整理提示词、查找标签、复制格式时少重复操作。

## 主要功能

魔导书里有一个标签库，标签按大类、子类和具体标签整理。使用时可以在左侧选择标签，选中的内容会自动进入提示词区域。

提示词区域支持正面词和负面词分开管理，也可以调整标签权重。整理好之后，可以直接复制中文或英文提示词。

如果标签比较多，可以用搜索筛选。常用标签也可以加入收藏，之后不用每次都从分类里重新找。

## v7.1 做了什么

这次 v7.1 主要改的是界面和操作逻辑。

顶部现在有几个工作区，包括创作、AI、识图、图片参考和标签管理。不同工作区可以放不同的面板。

面板系统也重新做了一部分，现在可以进行分割、合并、关闭和切换，使用方式有点参考 Blender 的多面板逻辑。布局也可以保存成预设，之后继续使用。

设置里增加了字体大小、界面密度和主题颜色相关选项，主要是为了适应不同屏幕和个人习惯。
